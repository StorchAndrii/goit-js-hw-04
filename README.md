# goit-js-hw-04

Домашнє завдання з JavaScript: робота з об’єктами, масивами об’єктів і
методами об’єктів.

## Структура

- `js/task-1.js` — перевірка місткості контейнера для товарів.
- `js/task-2.js` — розрахунок середньої кількості калорій.
- `js/task-3.js` — методи профілю гравця.

Відкрийте `index.html` у браузері та перегляньте результати виконання в
DevTools Console.
